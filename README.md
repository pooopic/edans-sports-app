# המעקב של עדן — תזונה ואימונים 🏋️🍽️

אפליקציית ווב (PWA) לשימוש אישי: תפריט שבועי, לוג אימונים ומסך התקדמות.
עברית, RTL, מותאמת למסך צר, וכל הנתונים נשמרים מקומית בדפדפן (localStorage) — עובדת גם בלי אינטרנט אחרי הטעינה הראשונה.

## איך מתקינים בטלפון (אנדרואיד)

1. מפעילים GitHub Pages על הריפו (Settings ← Pages ← Deploy from branch ← בוחרים את הענף ואת תיקיית root).
2. פותחים את הכתובת בכרום בטלפון.
3. תפריט ⋮ ← "הוספה למסך הבית" (Add to Home screen) ← האפליקציה נפתחת במסך מלא כמו אפליקציה רגילה.

## מה יש בפנים

- **תפריט שבועי** — יובא מגיליון "תפריט שבועי" באקסל: בוקר/צהריים/ערב + הערות לכל יום, סימון וי על ארוחות, הערכת חלבון יומית עם פס התקדמות מול יעד 130–140 ג׳, סימון ימי צום 16:8, עריכת ארוחות ושכפול שבוע קודם.
- **לוג אימונים** — ראשון/שלישי/חמישי: טיימר אינטרוולים 30/30 לקפיצה בחבל, רישום סטים/חזרות/משקל לסקוואט, לחיצה, חתירה ודדליפט רומני, מעקב מתח (מלא / גומייה 35 ק״ג / שליליים) וטיימר מנוחה.
- **התקדמות** — גרף חלבון מול יעד, גרף משקלים לכל תרגיל, גרף חזרות מתח מלאות ורצף אימונים.

## הרצה מקומית לפיתוח

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

(חייבים שרת — service worker לא עובד מ-file://)
